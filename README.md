## Лабораторная работа №1 Задача 1

Необходимо написать программу, которая вычисляет площадь треугольника по трём его сторонам (по формуле Герона) с точностью до сотых. Требования: пользователь вводит 3 числа; числа могут быть как целыми, так и дробными; результат должен быть выведен с двумя знаками после запятой.

## Среда разработки

Язык программирования: Python. Среда разработки: PyCharm 2025.2.4

## Инструкция по работе

По запросу программы пользователь вводит 3 стороны треугольника, а программа проверяет возможность существования треугольника с такими сторонами и считает его площадь.

## Лабораторная работа №1 Задача 2

Необходимо создать программу-конвертер, которая переводит расстояние из одних единиц измерения в другие. Программа должна поддерживать следующие единицы: километры (км), метры (м), сантиметры (см), миллиметры (мм), мили (mi), ярды (yd). Требования: пользователь выбирает исходную и целевую единицы измерения; программа запрашивает значение для конвертации, выводится результат.

По запросу программы пользователь выбирает исходную и целевую единицу измерения, а также значение переводимой величины.
